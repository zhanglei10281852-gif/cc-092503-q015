# 科研样品全生命周期管理服务

这是一个面向科研机构样品库、实验室和课题组的模块化后端，集中管理样品接收、分装、借用、归还、消耗、销毁、库存盘点、谱系事件、保管位置、异常记录、登录权限、审计以及可恢复后台任务。项目使用 FastAPI 与 SQLite，所有运行数据保存在单个本地数据库文件中，不依赖另行部署的数据库、缓存或消息队列。

## 已有能力

- 身份与权限：支持引导管理员、登录、会话、用户、角色和细粒度权限。
- 批次与二维码：接收批次保存项目、数量和稳定二维码载荷。
- 样品档案：登记样品、数量、单位、保管位置和生命周期状态。
- 分装谱系：一次事务内扣减母样、创建子样、记录损耗与事件链。
- 借用归还：保存借用数量、到期时间、部分归还和最终归还状态。
- 实验消耗：使用幂等键登记消耗，防止重复请求二次扣减。
- 位置脱敏：普通权限只能看到受限位置的替代码，授权人员可查看精确位置。
- 双人审批：高风险操作要求申请人与审批人分离，并累计不同审批人的决定。
- 异常追踪：异常可以关联样品或接收批次，保存严重度和处理状态。
- 审计与任务：关键身份及业务操作留痕，后台任务支持去重、领取与完成。
- 保存期限与到期评估：版本化保存策略（机构默认/样品类型/项目约定）、法律保留、论文复核引用与保留延期；每日评估任务支持检查点恢复，给出可解释的纳入/排除/推迟候选报告，并安全生成成组销毁计划。

## 保存期限与到期评估

- 保存策略按 `global`（机构默认）、`sample_type`（样品类型）、`project`（项目/合同约定）三个作用域版本化管理，项目约定优先于类型、类型优先于默认；任何修改只新增版本，旧版本标记 `superseded`，历史结论标记过期（`stale`）而不改写。
- 到期时钟以**接收时间**为起点，叠加策略保存天数、法定保留天数和已审批的保留延期。
- 以下情形不会被误列入销毁：正在借用（含部分归还/逾期/争议）、存在未结案异常（含批次级）、样品被论文复核引用、处于法律保留（样品/项目/类型作用域，可限期或无限期）、隔离中、有未完成双人审批的延期，以及其谱系后代仍被引用或法律保留。
- 研究负责人可申请有期限（1–3650 天）的保留延期，需两名不同审批人批准，申请人不能自审、同一审批人不能重复计票。
- 每日评估任务按批次提交检查点（`SAMPLE_RETENTION_BATCH_SIZE` 可调），进程中断后再次运行自动从检查点恢复；同一天重复运行幂等，不重复建结论或销毁单。
- 候选报告（`GET /api/retention/candidates/latest` 或按评估 ID 查询）逐条解释纳入（`included`）、排除（`excluded`）与推迟（`deferred`）原因及阻塞项。
- 成组销毁计划只能取自最新一次评估的、未过期的纳入候选；交出前再次实时核验借用/异常/保留/复核状态；策略指纹变化、候选已入计划或出现新阻塞都会拒绝建单。

### 每日定时入口

```bash
# 建议由系统 cron 每天执行：入队（按日期去重）并立即运行评估，可从检查点恢复
python -m app.cli retention-run

# 或仅入队，由常驻 worker 领取
python -m app.cli retention-enqueue
python -m app.cli retention-work --limit 20
```

也可通过 `POST /api/retention/evaluations/enqueue` 与 `POST /api/retention/evaluations/run` 触发。

## 运行环境

- Python 3.11
- SQLite 3，由 Python 标准库提供
- Linux、macOS 或 Windows

## 安装

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
```

默认数据库位于 `./data/samples.db`，可用 `SAMPLE_DATABASE_PATH` 指定其他路径。

## 初始化与完整性检查

```bash
python -m app.cli init-db
python -m app.cli check-db
```

## 启动 API

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## 测试

```bash
python -m pytest
```

python -m compileall -q app tests
